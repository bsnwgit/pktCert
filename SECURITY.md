# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately using [GitHub's private vulnerability reporting](../../security/advisories/new) rather than opening a public issue.

We'll acknowledge your report and work with you on a fix and coordinated disclosure timeline before any public details are shared.
